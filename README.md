# Dashain Wishes Web Page

A beautifully designed, interactive Dashain greeting web page with festive animations and cultural elements.

## Features

- Professional "झिलिमिलि" (sparkling) design
- Responsive layout for mobile, tablet, and desktop
- Animated elements (fireworks, firecrackers, flowers, confetti)
- Background music from YouTube
- Typewriter effects for Nepali text
- Durga Mata image with decorative side images
- Interactive elements with smooth animations

## How to Use

1. Open `dashain-wish.html` in a web browser
2. Click the "Reveal Dashain Wishes" button to see the animations
3. Toggle background music using the sound control in the bottom-right corner

## Customization

- Replace images in the `durga-container` div to customize the festive images
- Modify the Nepali text in the `nepali-text` paragraph
- Adjust colors in the CSS variables to match your preferred color scheme
- Change the background music by updating the YouTube video ID in the JavaScript

## Files

- `dashain-wish.html` - Main HTML file with embedded CSS and JavaScript
- `pngegg.png` - Decorative image for the right side
- `server.js` - Node.js server for local testing
- `server.py` - Python server for local testing

## Requirements

- A modern web browser
- Internet connection (for loading external fonts and images)
